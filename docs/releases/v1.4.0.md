# Global Executables v1.4.0

This release adds environment-aware installation guidance to the MCP server, command-line interface, and GitHub Pages Playground. The resolver shows a documented package-manager method, provider evidence, prerequisites, ordered install and invoke arguments, and a separate verification status. It does not execute installation commands or claim that every indexed package is available on the requested target.

The release also resumes scheduled Go catalog refresh after the crawl cursor reaches the previous catalog size and introduces a separate broad npm registry source alongside the daily critical npm tier.

## Published dataset

- Snapshot: 2026-10-19 (latest verified dictionary report at release preparation).
- Coverage kind: partial; 899,377 canonical executable names and 2,087,614 accepted observations in the latest verified refresh report.
- npm critical completion applies to its 2,295-package subset. The broad npm crawl and continually refreshed Go catalog have not yet met their completion criteria. Missing names remain subject to the published coverage caveats.
