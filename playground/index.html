PUBLIC NOTICE · AUGUST 26, 2026

Breaking npm coverage change

We apologize for changing the meaning of npm coverage without a prominent public notice.

On August 26, 2026, this service replaced its 4.3-million-package npm registry crawl denominator with a 2,295-package ecosyste.ms critical subset. The former crawl had reached 218,774 packages in the public checkpoint and 221,774 in the local checkpoint. The current “100%” indicator refers only to the 2,295-package critical subset; npm overall is not 100% covered.

This breaking change narrowed the active npm crawl population and broke comparison with earlier progress. A missing npm result is not proof that no npm package uses that executable name. The project tracks restoration of broader, multi-source npm coverage in Issue #54; the previous crawl evidence remains in Issue #42.
